# portfolio-hub
Portfólio acadêmico e profissional com projetos de programação, inteligência artificial e tecnologia.

## Sobre o projeto

Este repositório foi desenvolvido como parte da atividade de Bootcamp I.

O objetivo é apresentar meus projetos acadêmicos e pessoais nas áreas de programação, inteligência artificial e tecnologia.

## Organização

- documentacao: documentos relacionados ao portfólio.
- projetos/programacao: projetos de programação.
- projetos/inteligencia-artificial: projetos de inteligência artificial.
